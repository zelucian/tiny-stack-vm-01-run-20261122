A tiny, deterministic stack virtual machine in a single TypeScript file.
It runs every program in the input directory exactly to the ISA spec — wrapping
32-bit arithmetic, all eleven trap codes, and the 1,000,000-step and 65,536-byte
output limits — and writes each instance's stdout and exit code.
